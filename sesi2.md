## 5. Korelasi dengan Source Code Proyek Moni-JPP

1. **Modul Dokumentasi Kegiatan** : `App\Http\Controllers\Admin\DokumentasiController` (pengelolaan foto, dokumen PDF, link dokumentasi, visibilitas publik/privat).
2. **Multi-PO & Multi-Surat BAK** : Relasi tabel `pos`, `surat_bak_docs`, dan `permintaan_daris` pada `JobPackageController`.
3. **Audit Trail** : Model `ActivityLog` dan metode `logActivity()` pada `JobPackageController`.
4. **Monitoring Publik** : Controller `HomeController`, view `resources/views/public/home.blade.php` dan `job-package-show.blade.php`.
5. **Ekspor Excel** : Service `App\Services\JobPackageExportService` menggunakan library PhpSpreadsheet.
6. **User Management** : Controller `App\Http\Controllers\Admin\UserController`.
